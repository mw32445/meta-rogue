## 1. Foundation changes requested

### 1.1 New persistent function static: `_get_num_buf` (options.c `get_num`, MASTER)
`get_num()` has `static char buf[MAXSTR]`, which really persists: `get_str()` only
writes it when something is typed. In a second wizard `C`reate of gold, pressing
Enter alone reuses the previous amount. This is checked against the C: "123", then
Enter alone, gives 123 again.
- Now: a temporary `static var _get_num_buf := ""  # REQUEST` in `options.gd`.
- Please add `static var _get_num_buf := ""` to RogueBase and reset it to `""` in
  `reset()`. Then I (or you) delete the module var. The name already follows the
  `_<function>_<name>` convention.

### 1.2 Oracle: pin `md_getrealname` (MASTER only)
The wizard "names" listing in `score()` (type `names` at "[Press return to
continue]") prints `md_getrealname(sc_uid)`.
- The oracle calls the real `getpwuid(ROGUE_UID)`. In this container uid 1000 is
  `ubuntu`.
- `Mdport.md_getrealname` returns `env_name` (`rodney`).
- The two programs print different stdout. Please wrap `md_getrealname` in
  `hooks.c` (e.g. return `ROGUE_NAME`), or make the port match.

### 1.3 `main.gd` `-d` path hangs when the first `rnd(100)` is 0 (not my file; FYI)
`dnum = rnd(100); while (--dnum) rnd(100);` with `dnum == 0` wraps a 32-bit
`int` in C, so it makes 2^32-1 more draws.
- The LCG has full period 2^32, so the net effect is that `seed` steps back by one.
- `main.gd` uses 64-bit ints and never terminates. Seeds 1..4 do this, and I saw
  hangs with `--seed 1` and `--seed 2 --arg -d`.
- Suggestion: special-case `dnum == 0` and apply the inverse LCG step,
  `seed = ((seed - 13849) * inv(11109)) mod 2^32`, or wrap `dnum` to 32 bits.

### 1.4 `sprintf("%c", 0)` (FYI, edge case)
`RogueBase.sprintf` turns `%c` with 0 into `char(0)`. Godot makes that U+FFFD and
prints "Unicode parsing error".
- In C the NUL ends the C string. For `msg`/`printw` consumers the rest is lost;
  `printf` to stdout writes a 0 byte.
- It is reachable only through keys 0 or 128: `md_readchar` masks to 0x7F.
  Example: wizard `create_obj` "which %c do you want?" with such a key.
- I don't use `chr(0)` anywhere in my files.

### 1.5 `tools/check.sh --quick` (resolved)
Earlier the check of my three files failed only because the untracked `tests/replay.gd`
needed `RogueBase.env_cwd`, which existed only in the then-uncommitted `rogue_base.gd`.
Now that `rogue_base.gd` is committed, `GODOT=/root/bin/godot tools/check.sh --quick
godot/rogue/rip.gd godot/rogue/options.gd godot/rogue/wizard.gd` prints `compile: OK`
and lint finds 0 problems.

## 3. Notes / interfaces (for callers and for review)
- **`Options.get_str(vopt: String, win) -> Array`** returns `[NORM|QUIT|MINUS, new
  string]`, as you specified. **`Options.strucpy(s1, s2, len_) -> String`** returns
  what C writes at `s1`.
- **`Options.get_num(vp: int, win) -> Array`** (MASTER): `vp` is the value of the int
  `vp` points at; it returns `[retval, new int]`. `create_obj` stores `r[1]` into
  `obj.o_goldval`.
- **The option table** is an inner class `Options.Option`. `o_opt` is the
  RogueBase global's name (StringName), read and written by
  `_opt_get`/`_opt_set`. `o_putfunc`/`o_getfunc` are ids dispatched by
  `_putfunc`/`_getfunc`; `_getfunc` is a port-only coroutine.
  - `put_bool/put_str/put_inv_t(name)` and `get_bool/get_sf/get_inv_t(name, win)`
    take that "pointer", so writes happen at the same moment as in C. `get_sf`
    re-reads `see_floor` after `get_bool` wrote it.
- **`parse_opts`** upper-cases the inven value's first letter in place. In C this
  writes into the environment string, which `playit()` parses a second time. The
  port works on a local copy; the second parse gives the same result either way.
- **`Rip.Score`** (struct sc_ent) has fields `sc_uid sc_score sc_flags sc_monster
  sc_name sc_level sc_time` and `copy_from()`. `score()` passes `top_ten:
  Array[Score]` to `Save.rd_score`/`wr_score`.
- **`Rip.killname()`** returns the String and also sets `prbuf`, as C's static
  buffer does. **`Wizard.passwd()`** returns int (0/1).
  **`Wizard.type_name()`** returns a String, or null.
- **`death()`'s tombstone year** is
  `Time.get_datetime_dict_from_unix_time(env_time)["year"]`, i.e. UTC. Tests pin
  TZ=UTC; normal play differs from C's localtime only around New Year.
- **`Rooms.find_floor(null, c, 0, true)`**: I pass `limit` as int 0 (C `FALSE`),
  because the C parameter is an `int`.
