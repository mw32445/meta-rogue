# Gameplay changes

Deliberate changes to the game's behavior, relative to Rogue 5.4.4, go here. A change
to the port's behavior makes the differential tests fail wherever behavior differs, so
each entry should say how the classic behavior is kept testable (see CLAUDE.md:
"Gameplay changes and the 1:1 baseline").

With every switch off, the port is 1:1 with the original (the few documented
exceptions, such as fixes for undefined behavior and the two save bugs, are listed in
`FIDELITY.md`). The playable game (`godot/ui/main.gd`) turns the switches on;
`--classic` turns them off.

| 2026-10-11 | **Item menus, as in PC Rogue.** A command that asks for an item (read, quaff, eat, wield, wear, put on, zap, throw, drop, call, identify) lists the items that fit at once, in a window under the question, instead of "(* for list)".
