# Gameplay changes

Deliberate changes to the game's behavior, relative to Rogue 5.4.4, go here. A change
to the port's behavior makes the differential tests fail wherever behavior differs, so
each entry should say how the classic behavior is kept testable (see CLAUDE.md:
"Gameplay changes and the 1:1 baseline").

With every switch off, the port is 1:1 with the original (the few documented
exceptions, such as fixes for undefined behavior and the two save bugs, are listed in
`FIDELITY.md`). The playable game (`godot/ui/main.gd`) turns the switches on;
`--classic` turns them off.

| Date | Change | Switch / how classic mode stays testable | Files |
|---|---|---|---|
| 2026-10-11 | **Bug fixes.** The known bugs of 5.4.4 are fixed: keypad 5, `F` and `kamikaze`, `relocate`/`find_dest`, picking up into an empty pack, `save_game`'s unlink, the `conn()` hang, the "the the" and ring-off messages, `fall()`'s names, Create Monster on a xeroc, raise level at 21, the flytrap's damage, the off-map search, `%` in player text, the wide overwrite inventory, the daemon slots, magic missile without a weapon, the wraith's drain, the `amulet` flag, merge pickups, nymph theft, monsters killed during `runners()`, treasure-room overlaps, stairs after hallucination, scroll-title spaces, wizard-mode bugs and message typos. `docs/FIXES.md` has each bug, its fix and its script, and the bugs kept as they are (#6 dark mazes, #19, ...) with the reason. | `RogueBase.fixes`. The same fixes are in C (`harness/oracle/fixes.patch`, oracle variants `fixed`/`fixedmaster`), so `difftest.py --fixes` verifies the fixed game keystroke by keystroke; `run_all.sh` runs every batch both ways. Per-bug scripts in `harness/corpus/fixes/` carry `# expect-classic/fixed:` lines. | the bug sites in `godot/rogue/*.gd`, `godot/ui/terminal_view.gd` (keypad), `harness/oracle/fixes.patch`, `hooks.c`, `harness/corpus/fixes/`, `godot/tests/fixes_test.gd` |
| 2026-10-11 | **Item menus, as in PC Rogue.** A command that asks for an item (read, quaff, eat, wield, wear, put on, zap, throw, drop, call, identify) lists the items that fit at once, in a window under the question, instead of "(* for list)". Any pack letter picks an item, Escape cancels, space shows the next page, `*` switches to the whole pack. | `RogueBase.menus`, off in every differential test. Tests: `godot/tests/menus_test.gd`, and `difftest.py smoke --menus` (random games, the port alone: no script error, no hang). | `godot/rogue/pack.gd` (`get_item`, `_menu_item`) |
| 2026-10-12 | **The Guild's prices in a text file.** Every Guild price, growth rule and amount, and the coffers formula, are in `godot/guild_prices.txt` (plain text, commented, formulas with `k`, `base`, `^`, `lerp`, ...). The Guild reads it each time it opens; a line it can't use keeps its original value and is reported on the Guild screen. Exported builds look for it next to the executable, then in the user data folder. | Part of `RogueBase.guild`. Tests: `godot/tests/prices_test.gd` (the shipped file gives exactly the built-in prices; the formula language; errors), `guild_test.gd` (a shop with edited prices). | `godot/guild_prices.txt`, `godot/guild/formula.gd`, `prices.gd`, `shop.gd`, `catalog.gd`, `hall_of_fame.gd` |
| 2026-10-12 | **Video settings.** The first launch detects the screen and opens borderless fullscreen at its resolution (e.g. 1920 x 1080); F10 opens a menu (display mode, window size, monitor, VSync), Alt+Enter toggles fullscreen, `--windowed`/`--fullscreen` override it for a run. | None needed: interface only (`godot/ui/`), no game rule changes, and the differential tests never load the UI. Tests: `settings_test.gd`, `ui_video.gd` (real window). | `godot/ui/video_settings.gd`, `settings_screen.gd`, `main.gd`, `terminal_view.gd`, `project.godot` |
| 2026-10-12 | **Experience to the next level.** The status line shows the experience at which the next level starts: `Exp: 2/15/20` (level 2, 15 experience, level 3 at 20); at the last level, `Exp: 21/8000001`. If the line would reach the last column, its double spaces shrink. | `RogueBase.exp_next`, off in every differential test. Tests: `godot/tests/menus_test.gd` (5 checks), `difftest.py smoke --expnext`. | `godot/rogue/io.gd` (`status`, `_status_line_next`) |
| 2026-10-11 | **The Fighters' Guild.** Before every new game a shop spends the Hall of Fame's coffers (`best / 2 + (sum / 20) * lerp(0.5, 1.5, n / 20)`) on training (strength, hit points), your weapon and armour, spares and enhancements, rings, wands, identifications and known potions and scrolls, food, missiles and a bigger pack (up to 52 slots, letters `A`-`Z` past `z`). The Hall of Fame has 20 entries; a polished ring of adornment sells for more when you win. | `RogueBase.guild` (and `RogueBase.loadout`). Off in every differential test, so the classic game is untouched; its own tests are `godot/tests/guild_test.gd` and replays with `--guild --loadout F.json`. | `godot/guild/`, `godot/ui/main.gd`, `terminal_view.gd` (a taller end-of-game console), `main.gd`, `pack.gd`, `save.gd`, `rip.gd`, `things.gd`, `rogue_base.gd`; `docs/GUILD.md` |
